## ⚡ Overview

A high-performance, interactive portfolio showcasing AI engineering projects, research, and production workflows. Features a seamless scroll-driven 300-frame canvas sequence, smooth Lenis scrolling, glassmorphism design, interactive project case studies, and dynamic filtering.

## 🚀 Key Features

- **Scroll-Scrubbed Canvas Animation:** HTML5 `<canvas>` rendering 300 sequential portrait frames synchronized with GSAP ScrollTrigger and gradient edge blending.
- **Lenis Smooth Scroll:** Integrated with the GSAP ticker for 60fps stutter-free scroll performance.
- **Interactive Project Case Study Modals:** Clickable project cards revealing problem statements, technical architecture, benchmark metrics, and direct GitHub links.
- **Dynamic Category Filtering:** Filter projects across *AI & LLM Apps*, *Computer Vision*, and *Machine Learning & NLP*.
- **Impact Metrics Bar:** Animated counter statistics highlighting deployed AI agents, dataset volumes, and latency benchmarks.
- **Responsive Mobile Navigation:** Full-screen frosted-glass navigation drawer for mobile and tablet devices.
- **Direct Email Form & One-Click Copy:** Quick contact composer and clipboard copying with floating toast notifications.

## 🛠️ Featured Projects

1. **[ResumeBuilderAI](https://github.com/Samiaqadir/ResumeBuilderAI):** Mobile GenAI application built in React Native using the Groq Cloud API (`llama-3.1-8b-instant`) for sub-second ATS resume and cover letter generation.
2. **Voice + Gesture PC Agent:** Multimodal desktop companion with `faster-whisper` STT, `Piper` neural TTS, and automated OS actions.
3. **[CounselBot](https://github.com/Samiaqadir/CounselBot-main):** Career guidance AI platform with custom-trained TensorFlow/Keras neural networks (`.h5`), NLTK tokenizers, and interactive Streamlit UI.
4. **AI Employee Suite:** Multi-agent enterprise platform (HR, Sales, Support) with role-permissioned RAG vector retrieval.
5. **[Plant Disease Classifier](https://github.com/Samiaqadir/plantvillage-classification):** Deep Convolutional Neural Network trained on 50,000+ PlantVillage leaf images across 38 crop disease categories.
6. **Skin Disease Detection:** Dermatological triage CNN model integrated with a cross-platform React Native app and Firebase backend.
7. **[Movie Recommender System](https://github.com/Samiaqadir/Movie-recomendation-system):** Content-based movie filtering using TF-IDF feature transformations and cosine similarity on 5,000+ titles.

## 💻 Tech Stack

- **Frontend & Styling:** HTML5, CSS3, Modern JavaScript, CSS Grid, Flexbox, Glassmorphism
- **Animation & Motion:** GSAP 3.12, ScrollTrigger, Lenis Smooth Scroll

- **Mobile Stack:** React Native, TypeScript, AsyncStorage, Firebase

## 🏃‍♂️ Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Samiaqadir/Portfolio.git
   cd Portfolio
   ```
2. Start a local HTTP server:
   ```bash
   # Using Python
   python -m http.server 8000

   # Or using Node
   npx serve .
   ```
3. Open `http://localhost:8000` in your browser.
